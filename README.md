# Antonia Portfolio

Schlankes Portfolio-Projekt mit Astro, vorbereitet fuer GitHub Pages und kleine 3D-Akzente mit Three.js.

## Stack

- Astro fuer statische Seiten
- Three.js fuer einzelne 3D-Elemente
- CSS ohne UI-Framework
- Kein Framer Motion in der Basis, damit die Seite klein bleibt
- GitHub Actions fuer GitHub Pages

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Der statische Output landet in `dist/`.
